**[e107][1]** je bezplatný redakční systém (CMS) s otevřeným zdrojovým kódem, který vám umožní snadno spravovat a publikovat obsah online. Vývojáři ušetří čas při tvorbě webových stránek a výkonných online aplikací. Uživatelé se programování mohou zcela vyhnout! Blogy, webové stránky, intranety – e107 zvládne vše.

## Požadavky

   ### Minimální

   * Webový server (Apache nebo Microsoft IIS) s PHP 7.4 nebo novějším
   * MySQL 4.x nebo novější, nebo MariaDB
   * FTP přístup k vašemu webovému serveru a FTP klient (například FileZilla)
   * Uživatelské jméno a heslo k vaší MySQL databázi

   ### Doporučené

   * Apache 2.4 nebo novější na Linuxu
   * PHP 7.4 nebo novější
   * MySQL 5.6 nebo novější, nebo MariaDB 10.3 nebo novější
   * Registrovaná doména
   * Přístup k ovládacímu panelu serveru (například cPanel)

**Verze** používají [pesimistický operátor z Ruby](https://guides.rubygems.org/patterns/#pessimistic-version-constraint): `~> 2.3.0` odpovídá `>= 2.3.0, < 2.4.0`.
- **Vydání** je datum, kdy bylo zveřejněno první vydání dané řady.
- **Konec nových funkcí** je datum, po kterém se do dané řady nepřidávají žádné nové funkce.
- **Konec údržby** je datum, po kterém se v dané řadě již neopravují chyby ani bezpečnostní problémy.
- **Konec obnovy** je datum, po kterém je daná řada zcela opuštěna a s jejím obnovením se již nepočítá.

### Kompatibilita s PHP

| Verze softwaru      | Minimální verze PHP | Maximální verze PHP            | Příčina změny kompatibility |
|---------------------|---------------------|--------------------------------|-----------------------------|
| `~> 0.7`            | 4.3                 | _Neznámá_                      | První explicitní spodní hranice v `install.php` (`$required_php = '4.3'`). |
| `~> 1.0.0`          | 4.3                 | _Neznámá_                      | Stejná hranice při instalaci; mezi verzemi 0.7 a 1.0 není zdokumentována žádná práce na verzích PHP. |
| `>= 2.0.0, < 2.3.0` | 5.3                 | _Neznámá_                      | `install.php` přešel na konstantu `MIN_PHP_VERSION` nastavenou na `5.3`. |
| `>= 2.3.0, < 2.3.4` | 5.6                 | 8.1.*                          | `MIN_PHP_VERSION` zvýšena na `5.6`; zaveden `composer.json` s platformou `5.6` a `require.php` `>= 5.6`. PHP 8.2+ zobrazuje upozornění na zastaralé funkce (deprecations). |
| `~> 2.3.4`          | 5.6                 | _Žádná známá nekompatibilita_  | Přibalené opravy upozornění „`Cannot use bool as array`“, které PHP 8.5 povýšilo, a normalizace pro libxml ≥ 2.13 v `cleanHtml`. PHP 8.5 stále zobrazuje zbývající upozornění na `setAccessible()` a další zastaralé funkce. |
| `~> 2.4.0`          | _Bude určena_       | _Žádná známá nekompatibilita_  |                             |

**Verze softwaru** používá omezení verzí ve stylu Ruby. Omezení popisuje uzavřený rozsah verzí e107, pro který platí následující dva sloupce. Maximum může být _Žádná známá nekompatibilita_, pokud v době vydání nebyla dosažena žádná horní hranice; pozdější vydání PHP mohou přinést upozornění na zastaralé funkce, která zde nejsou zachycena.

## Instalace

### Standardní instalace

1. [Stáhněte si e107](https://e107.org/download).
2. Rozbalte stažený soubor do požadovaného kořenového adresáře webu.
   Často je to adresář s názvem `public_html`.
3. V prohlížeči otevřete skript `install.php` (např. `https://example.com/podadresar/install.php`)
4. Postupujte podle průvodce instalací ve vašem prohlížeči.



### Instalace přes Git (vývojářská verze)

1. Spusťte následující příkazy, přičemž '~' nahraďte kořenovým adresářem vašeho webu (nadřazeným adresářem `public_html`) a xxx:xxx požadovaným vlastníkem souborů e107.
   ```
   cd ~
   git clone https://github.com/e107inc/e107.git public_html
   chown -R xxx:xxx public_html
   ```
2. V prohlížeči otevřete skript `install.php` (např. `https://example.com/podadresar/install.php`)
3. Postupujte podle průvodce instalací ve vašem prohlížeči.



## Hlášení chyb

Před nahlášením problému se ujistěte, že používáte nejnovější verzi e107.
Chyby a návrhy na nové funkce můžete nahlásit na [stránce GitHub Issues projektu e107](https://github.com/e107inc/e107/issues).



## Přispívání do vývoje

* Pro každý GitHub issue, na kterém pracujete, pošlete 1 pull request.
* Ujistěte se, že se při porovnání souborů (diff) zobrazí pouze řádky, které jste skutečně změnili.
  Některé textové editory mění každý řádek; tomu je třeba se vyhnout.
* Doporučujeme nastavit `git pull` tak, aby ve výchozím stavu prováděl rebase na větev master, a vyhnout se tak zbytečným merge commitům. Nastavíte to ve své kopii repozitáře v souboru `.git/config` takto:
  ```
  [branch "master"]
    rebase = true
  ```
* Návod, jak začít, najdete v dokumentu [CONTRIBUTING](https://github.com/e107inc/e107/blob/master/.github/CONTRIBUTING.md).
